WEBEX-NOTIFIER
Pops a native macOS notification whenever you get a Webex DM or
@mention. No Slack, no admin approval, no app to keep open.

REQUIREMENTS
  - A Mac with python3 3.9+ (on it by default) + Terminal access.
  - Your own Webex/Cisco login. No shared secrets, no IT ticket.

INSTALL (about 2 minutes, one time)
  1. Copy or clone this folder anywhere, then in Terminal:
       cd webex-notifier
  2. Run:
       ./run.sh
  3. It sets itself up automatically and interactively -- just
     follow the prompts:
       - Opens developer.webex.com to register YOUR OWN personal
         Webex Integration (~30 sec: name it anything, set
         Redirect URI to exactly http://localhost:8734/, check
         the 3 scopes shown on screen, paste back the Client
         ID/Secret it gives you).
       - Opens a browser to sign in with your Cisco email.
       - Fires a test notification, then installs a personal
         cron job that checks every minute.

  NOTE - No banner on the test notification?
  Open System Settings > Notifications > find "Script Editor" >
  turn on Allow Notifications, set style to Banners/Alerts (not
  None). Then run "./run.sh notify-test" again.

EVERYDAY COMMANDS
  ./run.sh status         Show auth + cron state
  ./run.sh doctor         Diagnose/fix problems interactively
  ./run.sh check          Run one check now (skip the wait)
  ./run.sh notify-test    Fire a one-off test notification
  ./run.sh cron-uninstall Stop/remove the background check

TROUBLESHOOTING OAUTH ERRORS
  - "We've encountered an error. Try again later." -- almost
    always a redirect URI mismatch. Re-open your integration at
    developer.webex.com/my-apps and confirm the Redirect URI is
    EXACTLY http://localhost:8734/ (note the trailing slash),
    then save and retry.
  - "The requested scope is invalid." -- go back to the
    integration's Scopes section and make sure all three are
    checked: spark:messages_read, spark:rooms_read,
    spark:people_read. Save, then retry.

  Each person registers their own Webex Integration and keeps
  their own tokens under ~/.webex_notifier/ -- nothing here is
  shared between colleagues, and there's nothing sensitive in
  this folder to protect when you pass it along.
